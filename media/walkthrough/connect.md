# Connect a model

YargiX needs a model to think with. Pick whichever suits you — you can add more later and switch between them at any time.

## Use a subscription you already pay for

Sign in with **Claude Code**, **OpenAI Codex**, or **Google Antigravity** and YargiX uses your existing plan. No API key, no extra billing.

## Bring an API key

OpenAI, Anthropic, Gemini and OpenRouter are preset. Any other OpenAI‑compatible or Anthropic‑style endpoint works too — just paste a base URL and key.

## Stay entirely offline

YargiX has **llama.cpp built in**. Search Hugging Face for a GGUF model, pick a quantization, download it, and YargiX runs and manages the server for you. Already using **Ollama**? It is detected automatically.

With a local model and the local index, nothing leaves your machine.

---

Open **Settings → Providers** to choose.
